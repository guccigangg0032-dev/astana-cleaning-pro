# ACPro — первый запуск на Windows (без Codex)

Цель первого шага — подтвердить, что локальный Ollama и Qwen действительно работают. Ни одна команда здесь не публикует посты, не отправляет сообщения и не требует ключей Instagram.

## 1. Проверка локальной модели

На компьютере откройте **PowerShell** и выполните:

```powershell
ollama list
```

Ожидаем: список скачанных моделей, среди них модель с `qwen` в имени. Если `ollama` не найден, сначала необходимо установить или запустить Ollama. **Не скачивайте новую большую модель без проверки ресурсов компьютера.**

Дополнительно:

```powershell
Invoke-RestMethod http://127.0.0.1:11434/api/tags
```

Это обращение исключительно к **вашему компьютеру**, не к платному API.

## 2. Проверка подготовленного ядра ACPro

Если репозиторий уже открыт на Windows, перейдите в его каталог. Если его ещё нет на компьютере, скачайте архив с официальной страницы GitHub:
https://github.com/guccigangg0032-dev/astana-cleaning-pro → Code → Download ZIP, затем распакуйте.

Из корня репозитория:

```powershell
py -3 -m unittest discover -s bot/tests -v
py -3 bot/check_local.py
py -3 bot/check_local.py --chat
```

Если команда `py -3` не найдена, проверяйте `python --version`, нужен Python 3.10+; затем используйте `python` вместо `py -3`.

`check_local.py` использует только локальный Ollama по адресу `127.0.0.1:11434`, определяет установленную модель Qwen и отправляет один безопасный тестовый вопрос. **Не пересылает реальные клиентские данные.** Ни при каких условиях программа не пишет в Instagram или Threads.

## 3. Интерпретация результата

- `Ollama API: OK` + `Qwen model: ...` + `SMOKE TEST PASSED`: локальная модель отвечает и открыто признаёт, что она ИИ; это **ещё не означает, что можно включать прямые ответы клиентам**.
- `NOT READY: local Ollama API is unavailable`: запустите Ollama.
- `Qwen model: NOT FOUND`: установлен другой ИИ или Qwen ещё не загружен.
- `NEEDS REVIEW`: генерация работает, но ответ не прошёл обязательную проверку раскрытия ИИ.
- На ответы на казахском требуется отдельная проверка носителем.
