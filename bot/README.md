# ACPro · бесплатное ядро ответов (подготовлено, пока без Meta)

**Статус:** код готов для локального dry-run. Он НЕ подключён к аккаунтам ACPro и НЕ отправляет сообщения. Подключение Qwen/Ollama, Instagram/Threads API и публикации — отдельный этап после проверки прав.

## Состав

- `answers.csv` — 53 сценария на RU/KK/EN, включая раскрытие ИИ и маршрут к разработчику.
- `engine.py` — нормализация, выбор ответа, контакты, правила жалоб, время Астаны, ограничения в публичных комментариях.
- `QWEN_SYSTEM_PROMPT.md` — политика будущего локального Qwen.
- `tests/test_engine.py` — автоматические проверки.

## Быстрый запуск Windows (Python 3.10+)

```powershell
python bot\engine.py --text "Вы бот?"
python bot\engine.py --text "Кто разработчик?"
python -m unittest discover -s bot/tests -v
```

Для интегратора доступен режим JSONL:

```json
{"event_id":"ig_001","conversation_id":"example_42","channel":"instagram_dm","text":"Сколько стоит уборка?"}
```

```powershell
python bot\engine.py --jsonl --db "$env:USERPROFILE\acpro-bot-state.sqlite"
```

Состояние содержит только хешированные идентификаторы, времена событий и 24-часовую блокировку после передачи человеку. Не храните DB в папке сайта и не сохраняйте туда пароли/API-токены. Тексты исходящих сообщений возвращаются на stdout, **ничего не отправляется в соцсети автоматически**. Перед использованием с вебхуками нужен отдельный обработчик подтверждённых событий Meta, проверка подписи, производственный журнал, устойчивое управление очередью и правами человека.

## Предварительные расчёты: Qwen 3.5 + обычный бот

**Работает в локальном тестовом режиме, НЕ подключено к Instagram/Threads.** Расчёты ведёт `quote.py` по каталогу `pricing_catalog.json`. Цены и минимальные суммы сверяются с кодом живого калькулятора `script.js` и списком допуслуг в `site.js` автоматическими тестами.

- `quote.py` — общая детерминированная арифметика для обоих ботов, поддержка RU / KK / EN.
- `engine.py` — обычный бот сам распознаёт типичные просьбы о расчёте и использует `quote.py`.
- `qwen_quote.py` — локально запрашивает Qwen 3.5 по Ollama на `127.0.0.1:11434`, берёт **только структурированные поля** и считает через `quote.py`; числа, написанные моделью, не принимаются как цены.
- `TEST_QWEN_WINDOWS.cmd` — двойной щелчок в Windows для теста одной фразы, без PowerShell, установки пакетов и публикаций.

### Тест на Windows

Распакуй обновлённый репозиторий (GitHub → Code → Download ZIP), зайди в папку `bot` и дважды нажми `TEST_QWEN_WINDOWS.cmd`. Используется уже установленный `qwen3.5:4b`. Нужен Python 3.10+, его наличие скрипт проверяет и **ничего не устанавливает**.

Альтернативный способ:

```powershell
python bot/quote.py --text "Сколько стоит генеральная уборка 50 м2 и диван?"
python bot/qwen_quote.py --text "Сколько стоит генеральная уборка 50 м2 и диван?" --model qwen3.5:4b
```

Ожидаемый **предварительный** ориентир: генеральная 50 м² 45 000 ₸ + двухместный диван 10 000 ₸ = **от 55 000 ₸**. Окончательную цену подтверждает человек. При отсутствии Qwen `qwen_quote.py` использует консервативный разбор обычного бота; такой fallback нельзя путать с подтверждением, что модель работает.

По отдельным услугам «по запросу» сумма не придумывается; при смешанных заявках она не включена в предварительный итог. Если несколько предметов, итог за количество автоматически не утверждается. Индукционные панели отдельно 15 000–25 000 ₸ по размеру, доступность специалиста не подтверждена.

**Внимание:** это зеркальный справочник текущих тарифов сайта, а не живое чтение тарифов из Plesk на каждый запрос. Если цены на сайте меняются, надо обновлять `pricing_catalog.json` в том же выпуске. Автоматические тесты проверяют расхождения в исходном GitHub, но не делают самостоятельную синхронизацию с Hoster.kz.
