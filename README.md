# ASTANA CLEANING PRO · Сайт

Готовый адаптивный сайт с отдельным расчётом стоимости клининга и отправкой заявки в WhatsApp.

## Быстрый просмотр

Откройте `index.html` в браузере. Для локальной проверки со всеми переходами можно выполнить:

```bash
python -m http.server 8000
```

И открыть `http://localhost:8000`.

## Публикация без изменений NEXON

1. Создайте **новый, отдельный публичный репозиторий** `astana-cleaning-pro` в отдельном репозитории (не затрагивая NEXON) (не вносите изменения в `ARGif-tech.github.io`).
2. Загрузите **содержимое этой папки** в корень нового репозитория, сохранив структуру `assets/`, `index.html`, `styles.css`, `script.js`, `.nojekyll`.
3. В новом репозитории откройте Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. После публикации адрес будет `https://guccigangg0032-dev.github.io/astana-cleaning-pro/` (проверьте реальную доступность после включения GitHub Pages).

## Настройки

- Номер WhatsApp/телефона: +7 777 614 66 64 (в ссылках и тексте).
- Для изменения тарифов используйте объект `tariffs` в `script.js`.
- Ставки: поддерживающая от 400 ₸/м² (минимум 18 000 ₸), генеральная от 900 ₸/м² (минимум 38 000 ₸), после ремонта от 1 200 ₸/м² (минимум 52 000 ₸).
- Дополнительные услуги калькулятора: двухместный диван 10 000 ₸, кресло 5 500 ₸.
- Это **предварительные** коммерческие расценки: подтвердить с собственником перед запуском платной рекламы.
- Никаких вымышленных отзывов, цифр клиентов или фото чужих «наших работ» нет.
- Вся логика в браузере. Личные данные не собираются на сайте: заказ составляется в WhatsApp и отправляется только после подтверждения клиентом.
- При использовании своих реальных фото выполненных работ получите согласие заказчика и разместите их вместо иллюстраций.

## Технические особенности

HTML/CSS/JS без сборки, сторонней CRM и платного хостинга. Калькулятор действует на стороне пользователя. Разметка SEO (`title`, `description`, `schema.org ProfessionalService`), `sitemap` добавляется после подтверждения рабочего адреса.

Примечание по безопасности: озонирование не должно рекламироваться как универсальная очистка воздуха или стопроцентная дезинфекция; при работе с озоном помещение должно быть пустым. Специальные работы после пожара возможны только после оценки безопасности объекта.
