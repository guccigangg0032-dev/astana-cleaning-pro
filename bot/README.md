# ACPro · бесплатное ядро ответов (подготовлено, пока без Meta)

**Статус:** код готов для локального dry-run. Он НЕ подключён к аккаунтам ACPro и НЕ отправляет сообщения. Подключение Qwen/Ollama, Instagram/Threads API и публикации — отдельный этап после проверки прав.

## Состав

- `answers.csv` — 53 сценария на RU/KK/EN, включая раскрытие ИИ и маршрут к разработчику.
- `engine.py` — нормализация, выбор ответа, контакты, правила жалоб, время Астаны, ограничения в публичных комментариях.
- `QWEN_SYSTEM_PROMPT.md` — политика будущего локального Qwen.
- `tests/test_engine.py` — автоматические проверки.

## Быстрый запуск Windows (Python 3.10+)

```powershell
python bot\engine.py --text "Вы бот?"
python bot\engine.py --text "Кто разработчик?"
python -m unittest discover -s bot/tests -v
```

Для интегратора доступен режим JSONL:

```json
{"event_id":"ig_001","conversation_id":"example_42","channel":"instagram_dm","text":"Сколько стоит уборка?"}
```

```powershell
python bot\engine.py --jsonl --db "$env:USERPROFILE\acpro-bot-state.sqlite"
```

Состояние содержит только хешированные идентификаторы, времена событий и 24-часовую блокировку после передачи человеку. Не храните DB в папке сайта и не сохраняйте туда пароли/API-токены. Тексты исходящих сообщений возвращаются на stdout, **ничего не отправляется в соцсети автоматически**. Перед использованием с вебхуками нужен отдельный обработчик подтверждённых событий Meta, проверка подписи, производственный журнал, устойчивое управление очередью и правами человека.
