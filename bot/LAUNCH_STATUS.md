# ACPro · что готово и что необходимо для реального запуска

**17 октября 2026 года.** Этот комплект создан без Codex и без платных LLM API.

## Сделано и проверено в этом комплекте

- 53 сценария RU / KK / EN на основе версии ACPro v3, добавлены новые ответы об ИИ-менеджере и разработчике.
- Исправлено представление «Я ИИ-менеджер, не человек»; обычные клининговые заявки и запросы разработчику идут на разные номера.
- Локальное ядро ответов на Python, не использующее облачные API и внешние зависимости.
- 22 автоматические проверки прошли успешно: идентичность ИИ, маршрутизация, жалобы, время Астаны, языки, дубли, лимит ответов и человеческий контроль.
- Тестовый скрипт и готовый системный промпт для будущего локального Qwen.
- 7-дневный контент-план для Instagram и Threads.

## Пока НЕ сделано

- **Meta не подключена к ACPro.** Подключение Instagram/Threads через официальные API и права App Review не проверены; имеющиеся подключённые аккаунты в другом инструменте относятся к ARworks.kz.
- **Qwen пока не запущен этим комплектом на Windows ПК пользователя.** Создан набор правил, но нет подтверждённого постоянного процесса Ollama/Qwen, API сервера и мониторинга.
- Нет webhook-обработчика Meta и подтверждённой отправки сообщений/публикаций.
- Нет проверенного автоматического поиска публичных заявок.
- Нет производственной очереди постинга Reels, Stories и Thread, в частности реальных видео и права на контент нужно получить от владельца.
- Не подтверждены юридические формальности по ИП, персональным данным и размещению рекламы.

**Важно:** не использовать локальный dry-run движок как готового Instagram-бота. Любое реальное исходящее сообщение должно отправляться лишь после подтверждённой авторизации, проверки подписи входящего события, тестирования и включения канала владельцем.

## Рекомендуемый порядок без платных подписок

1. Локально поднять Qwen/Ollama на Windows, проверить производительность и корректность на RU/KK/EN.
2. Meta Developer: подключить именно @astanacleaningpro, минимально необходимые разрешения и законные каналы (Instagram Direct, комментарии, Threads, публикации).
3. Встроить dry-run классификатор + Qwen в единую очередь; webhook HTTPS, валидация Meta, ограничение скорости, защита от дублей, живая передача.
4. Прогнать тесты и перепроверить казахские ответы с носителем языка, настроить отложенную отправку и ручное подтверждение исходящих публичных сообщений.
5. Публиковать только реальные фото и видео работ, запустить контент-план с контролем расходов и качества.
6. Собирать показатели: реальные обращения, стоимость привлечения, подтверждённые заказы, жалобы и переходы с каждой площадки. Клики WhatsApp не считать автоматически заказами.
