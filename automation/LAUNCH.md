# Astana Cleaning Pro: Instagram + Qwen + Threads

**Статус:** серверный и локальный код подготовлен. Пока не развёрнут на `acpro.kz`, Meta Webhooks не зарегистрированы в действующем приложении, а токены НЕ добавлены в закрытые настройки. Это не утверждение о работающей интеграции.

Запуск сайта-чата отложен по просьбе владельца. Публикация Instagram Reels/Stories потребует реальные исходные фото и видео; этот комплект пока не содержит очереди Reels, Stories и автоматического ответа на комментарии. Threads: первичная публикация текстов и чтение публичных результатов поиска, не автоматическое комментирование чужих постов.

## Уже проверено

- PHP 8: синтаксис входящего Instagram Webhook и защищённого локального реле.
- Локальные тесты: подтверждение Meta с правильным токеном; отказ неправильному; отклонение неподписанных POST; приём корректно подписанного сообщения и защита от повтора; запрет незащищённого HTTP для рабочего реле.
- Тесты НЕ отправляли клиентам сообщения и НЕ публиковали посты.
- Локальный Ollama и Qwen 3.5:4b ранее подтверждены владельцем на Windows; 55 000 ₸ по примеру «генеральная 50 м² + двухместный диван» проверены. Этот новый агент на реальных событиях Meta ещё не испытан.

## Развёртывание на Hoster.kz / Plesk (без нового хостинга)

**Сохрани резервную копию** текущего `httpdocs` в Plesk прежде чем менять файлы. В GitHub изменения сами не публикуются на Hoster.kz.

1. В панели Plesk, менеджер файлов, открой корень подписки ACPro, **не `httpdocs`**. Создай `private-acpro-meta` на одном уровне с `httpdocs`.
2. Скопируй в него `config.example.php` с новым именем **`config.php`**, сохрани права доступа только владельцу аккаунта. Заполни **прямо в закрытом редакторе Plesk**:
   - `app_secret`: **секрет приложения Meta App**; это не access token и не app ID.
   - `verify_token`: придуманный длинный случайный секрет, такой же затем будет в Meta Webhook.
   - `worker_token`: **другой** случайный секрет длиной не менее 32 символов, потребуется на Windows.
   - `instagram_access_token`: токен именно `@astanacleaningpro`, полученный через Instagram Login с разрешением сообщений.
   - `instagram_account_id`: цифровой Instagram Professional user ID этого же аккаунта; получи его из Instagram API `GET /me?fields=user_id,username` с токеном. Не подставляй ID страницы Facebook/ARworks.
   - `replies_enabled`: **пока `false`**, поменять на `true` после успешного получения входящего тестового сообщения и подтверждения маршрута.
3. Загрузить **только** `api/ig-webhook.php` и `api/ig-relay.php` в `httpdocs/api/`. Не выкладывай `config.php`, токены, `.ps1` и `.json` из личных настроек в `httpdocs` или GitHub.
4. В Meta Developers → наше приложение AstanaCleaningPro → Instagram → Webhooks:
   - Callback URL: **`https://acpro.kz/api/ig-webhook.php`**
   - Verify Token: точно как в приватном `config.php`.
   - Сохранить проверку и подписаться на поле `messages`. Затем включить переключатель Webhook subscription у **`@astanacleaningpro`**. Это ещё НЕ включает автоответы.
5. Отправь одно тестовое Direct с другого Instagram-аккаунта, который действительно может писать ACPro. В корне подписки должен появиться файл `private-acpro-meta/queue/<hash>.json`. Он содержит текст сообщения и scoped ID, **содержит персональные данные**, не публикуй и не пересылай эти файлы.
6. Для Windows (где работает Ollama): создай локально `%APPDATA%\ACPro\instagram-bridge.json` со следующим содержимым (значение `worker_token` из закрытого серверного `config.php`):

   ```json
   {"server_url":"https://acpro.kz","worker_token":"INSERT_PRIVATE_WORKER_TOKEN","model":"qwen3.5:4b","mode":"live"}
   ```

   Сохраняй только локально в профиле владельца Windows, не в GitHub и не на сайте. Файл с токеном доступен владельцу Windows, обеспечь защиту учётной записи. Двойной щелчок по `windows/START_INSTAGRAM_AGENT.cmd`, окно оставь открытым, компьютер не должен уходить в сон. Агент не требует Python. В режиме `live` ответы отправляются **только при** `replies_enabled=true` в закрытом конфиге Plesk.
7. После того как агент увидел входящее событие и готовый ответ прошёл проверку, измени `replies_enabled` на `true`. Теперь **все новые сообщения**, поступающие через разрешённый Instagram Webhook, могут получать автоответы. Если жалоба или запрос живого менеджера: один ответ с человеческим контактом и 24-часовая пауза по диалогу. Выключение: `replies_enabled=false`; остановка агента: закрой окно.

**ПРИМЕЧАНИЕ:** модель Qwen сама не должна считать цены: локальный агент использует фиксированные утверждённые тарифы для распознанных типовых запросов. Код на PowerShell ещё не прошёл реальное тестирование на Windows пользователя; до запуска на реальных клиентах обязательно проверить отображение кириллицы и путь к Ollama. При запросах, на которые нельзя достоверно посчитать сумму, перевод к менеджеру.

## Threads: публикация и публичный поиск заявок

1. В Meta Developers → Threads API получи **отдельный токен Threads** от имени **@astanacleaningpro**, с реальными правами `threads_basic`, `threads_content_publish`, `threads_keyword_search`, `threads_read_replies`, `threads_manage_replies` (какие одобрены). Токен Instagram здесь не подходит.
2. На Windows создай `%APPDATA%\ACPro\threads-private.json`:

   ```json
   {"enabled":true,"threads_token":"INSERT_THREADS_USER_ACCESS_TOKEN"}
   ```

3. После проверки прав запусти `threads/ACPRO_THREADS_DAILY.ps1` через Windows PowerShell или `.cmd` запуска. Он публикует один **оригинальный** текстовый пост в сутки по времени Астаны и записывает локальное состояние, чтобы не создавать дубли. Контент в `threads/threads_posts.json` (7 постов на первую неделю; по окончании файл прекращает публикации, пока не подготовлен новый пакет контента).
4. `threads/ACPRO_THREADS_LEADS.ps1` собирает ссылки и короткие отрывки публичных публикаций по тематическим поисковым запросам. Это поисковая подборка, а **не** подтверждённые реальные заявки. Не рассылает DMs и комментарии без отдельного согласования.
5. Для ежедневного запуска создай в Windows **Планировщике задач** расписание, указывающее PowerShell и путь к нужному `.ps1`. Нужен работающий компьютер, сеть, токен и реальные разрешения. Без подтверждения правильного токена задачи не начнут работу.

## Ограничения для полноценного запуска

- Meta App в режиме development может ограничивать реальную работу с внешними пользователями; нужны соответствующие разрешения и, если Meta требует, App Review/Live. **Галочки сценариев не означают их автоматического одобрения.**
- Instagram Direct: отвечаем только человеку, который сам написал ACPro. Массовые инициативные DMs нельзя.
- Реальные фото/Reels/Stories отсутствуют в комплекте; без них не запускаем «видео уборки» из фиктивного материала.
- Автопубликация Threads работает лишь при корректном токене; алгоритм поиска публичных тем может возвращать пусто и подпадает под лимиты.
- Весь ИИ идёт через **локальную модель Ollama**; при выключенном ПК ответы прекращаются.
- Срок хранения новых текстовых событий в очереди до 24 часов. Завершённые события сохраняют минимальное состояние; требуется периодическая очистка архивов и политика персональных данных до массовой эксплуатации.
- Не публикуй `app_secret`, access tokens и worker token в чате, GitHub или скриншотах.

**Цель первой рабочей проверки:** один тестовый Direct виден в закрытой очереди, локальный Qwen формирует ответ, официальный Meta API подтверждает исходящее сообщение. После этого можно включить массовый режим без отдельного многонедельного пилота, если текущие разрешения Meta действительно позволяют.
